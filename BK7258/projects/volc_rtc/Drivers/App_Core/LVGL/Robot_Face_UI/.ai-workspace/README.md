# Beken LVGL UI Designer · AI 设计

这是当前项目的 AI 设计工作区。在聊天窗口描述界面需求，AI 会通过 MCP 工具直接修改 Beken LVGL UI Designer 中画布的内容。

---

## 1. 确认 MCP 已安装并加载

**首次使用：** 在 Beken LVGL UI Designer 工作台点击工具栏 `AI设计` → 选择 `Cursor`、`Codex`、`TRAE` 或 `TRAE CN`。

**确认加载成功：**

| 检查方式            | 正常表现                                 |
| --------------- | ------------------------------------ |
| Cursor / Codex / TRAE / TRAE CN 设置 → MCP | 列表中有 `beken_lvgl_ui_designer`，状态为已连接 |

**TRAE 注意事项：** 如果 TRAE 提示找不到 MCP，请使用完整名称 `mcp.config.usrlocalmcp.beken_lvgl_ui_designer`。

**若 MCP 未加载：** 关闭 Cursor / Codex / TRAE / TRAE CN，重新从 Beken LVGL UI Designer 的 `AI设计` 入口打开本目录。不要手动打开其它文件夹。

---

## 2. 对话生成界面

**怎么聊：** 在当前窗口像跟设计助手说话一样描述需求即可。

**示例：**

```text
1. 把首页改成设备状态面板：顶部标题，中间显示温度和湿度，底部三个操作按钮。
2. 修改page_2页面背景颜色为红色
3. 当前页面中添加一个按钮，背景颜色为蓝色，文字为白色，标题显示:Ok
4. 将标题颜色改为绿色，字号改为20
5. 为当前页面设计一张科技风的背景图片
6. 给保存按钮设计一个图标，尺寸32 * 32
```


**描述技巧：**

- 说明要改哪个页面、整体布局和各区域内容
- 可补充颜色、字号、间距等视觉要求
- 每次做一个明确改动，看效果后再继续

**修改确认：** AI 改完画布后，底部会出现 `保存` / `撤销`。

- `保存` — 接受本次修改
- `撤销` — 恢复到 AI 开始修改前的状态
- 若继续手动编辑或发起新一轮 AI 对话，未确认的修改会自动保存
